🎯 Version 1.3.3 - Recurring Events Update

July 15, 2025

What's Changed

  • Monthly Recurrence Temporarily Disabled - While we improve this feature, monthly recurring events are temporarily unavailable. You'll see a helpful message suggesting alternatives.
  • Fixed UPDATE Button - The UPDATE button now works properly when editing recurring events.
  • Better Error Handling - Improved stability when creating recurring events.

Why These Changes?

We discovered some issues with monthly recurring events that could cause unexpected behavior. Rather than risk problems with your events, we've temporarily disabled this option while we work on a more robust solution. Daily and weekly recurring events continue to work normally.

💡 Tip: If you need monthly events, consider creating individual events or using weekly recurrence as a temporary workaround.

📱 Version 1.4.3 - Mobile Experience Fix

July 15, 2025 (Evening Update)

What's Fixed

  • iPhone Calendar Events - You can now tap once to open event details! We fixed an issue where iPhone users had to double-tap calendar events.

Technical Details

The swipe navigation feature was interfering with event taps on mobile devices. We've updated the touch handling to ensure smooth interaction with calendar events while maintaining swipe functionality.

📝 Version 1.4.4 - Text Formatting Fix

July 15, 2025 (Late Evening Update)

What's Fixed

  • Event Description Formatting - Line breaks and paragraphs in event descriptions now display properly! Your carefully formatted event descriptions will appear exactly as you intended.

Why This Matters

Many organizers format their event descriptions with multiple paragraphs, lists, or line breaks for better readability. This fix ensures your formatting is preserved and displayed correctly to users viewing your events.
