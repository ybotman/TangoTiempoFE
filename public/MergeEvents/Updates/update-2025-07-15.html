🎯 Version 1.3.3 - Recurring Events Update

July 15, 2025

What's Changed

  • Monthly Recurrence Temporarily Disabled - While we improve this feature, monthly recurring events are temporarily unavailable. You'll see a helpful message suggesting alternatives.
  • Fixed UPDATE Button - The UPDATE button now works properly when editing recurring events.
  • Better Error Handling - Improved stability when creating recurring events.

Why These Changes?

We discovered some issues with monthly recurring events that could cause unexpected behavior. Rather than risk problems with your events, we've temporarily disabled this option while we work on a more robust solution. Daily and weekly recurring events continue to work normally.

💡 Tip: If you need monthly events, consider creating individual events or using weekly recurrence as a temporary workaround.
