Version 1.1.1 - July 4, 2025

New Features

  • Recurring Events (Beta): Create events that repeat daily, weekly, or monthly. Look for the "Repeating" toggle when creating or editing events.

  • Both Regional Organizers and Regional Admins can create recurring events
  • Version number in header now updates automatically

Bug Fixes
